# atlasai-photos-host

Hospedagem pública temporária das imagens de posts de foto/carrossel do AtlasAI, usada exclusivamente pela API de publicação de fotos da TikTok (`PULL_FROM_URL`).

Repositório separado de propósito do `atlasai-site` - aqui só existem imagens transitórias, apagadas automaticamente depois que a TikTok confirma o recebimento do post. Nada aqui é permanente.
